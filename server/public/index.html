Services

Each service is checked every minute by the server it runs on, and counts as up only while that server is online.

Add a service

An http(s):// address must answer with a status under 400, a ws(s):// one must accept the WebSocket, a tcp://host:port one must accept the connection.

That server checks it, so a 127.0.0.1 address reaches the service on it.
